WELCOME TO RASAM

Your first invoice, step by step.

  1. Try the example

    A fictional invoice is already here. Change a detail and watch the totals check respond.

  2. Review and approve

    Check the values against the source, tick the review box, then approve. Editing an approved invoice sends it back for review.

  3. Export to Excel

    Download a real .xlsx file containing only approved invoices. Sample rows are labeled so you can tell them apart.

  4. Try your own file

    Start the localhost launcher and add your OpenAI API key in its hidden terminal prompt. Upload a PDF or image, then choose Read with AI. Review the draft and any warnings before approval. Account coding and ERP posting are not connected.

This prototype checks that net + tax equals total. It does not verify tax rules or produce a posted journal. Your session clears when you refresh or close the tab.
