WELCOME TO RASAM
Your first invoice, step by step.
  1. Try the example
    A fictional invoice is already here. Change a detail and watch the totals check respond.
  2. Review and approve
    Check the values against the source, tick the review box, then approve. Editing an approved invoice sends it back for review.
  3. Export to Excel
    Download a real .xlsx file containing only approved invoices. Sample rows are labeled so you can tell them apart.
  4. Try your own file
    Follow the local app setup guide, then start the launcher. Free local OCR needs no API key. Add optional Ollama AI to organize recognized text on your computer, with no per-read API charge. Upload a PDF or image and choose Read invoice. Groq and OpenAI remain optional cloud readers selected in the launcher.
Check every draft against the original, especially unclear Arabic text and amounts. This prototype checks that net + tax equals total. It does not verify tax rules or produce a posted journal. Your session clears when you refresh or close the tab.
